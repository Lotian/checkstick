囍签 · 现场操作图解

给完全没用过的人看的一页纸：谁做什么、玩家看到什么、后台点哪里。

玩家端 = 玩家手机上打开的页面 管理端 = 工作人员电脑上开着的工作台 一台服务器把两边连起来

0先看懂这一张图

整套东西只有三个角色、一条主线。看懂这三个框，后面全是细节。

玩家：扫码 → 抽身份

用手机扫海报上的二维码，先读故事，再输入桌面立牌上的 4 位数字，然后亲手点「启签」抽一个身份，把身份卡拿给工作人员看。

他只需要会：扫码 + 输 4 个数字 + 点按钮
🖥️

工作人员：开轮 → 发身份

在电脑上打开管理端，选好这一桌，点「开新轮」放出一批签。看着实时进度，人够了可以「提前封签」，人满会自动封签。

他只需要会：开机→登录→开新轮→看数字
⚙️

后台内容：故事 + 身份卡文字

故事简介（玩家开场读到的那段）、每个身份的任务和奖励，都在管理端里改，改完玩家刷新就能看到。不用改代码、不用重启。

改文字：故事简介 / 身份内容
三句话记住整个系统：
① 海报上的二维码永远是同一个，不用换。
② 每张桌子有一个固定的 4 位数字组局码，写在桌面立牌上，玩家要自己输入。
③ 一「轮」就是一批签，签抽完了（或工作人员提前封签）就得开新轮，玩家才能继续抽。

1从头到尾会发生什么

按时间顺序，左边是工作人员做的事，右边对应的就是玩家看到的东西。

开场前布置现场海报贴二维码，桌面立牌写组局码，后台点「打印二维码」
▶
开始前 1 分钟开新轮点「开新轮」，一批签就发出来了
▶

现场工作人员看进度已落签数字自己往上跳，新郎/新娘是否已出也看得到
▶
人够了提前封签（可选）抽满最低人数后，可以不等满员直接封签
▶
人满了自动封签抽满最高人数，系统自己封，玩家看到「本轮签尽」
▶
下一批再点开新轮玩家点「查看新轮」就能继续抽
人数规则（只有这一条，记住就行）：
签位数量 = 后台设的最高人数（比如设 5~8 人，就准备 8 支签）。
抽满最低人数（5 人）后，「提前封签」按钮才会亮起来。
抽满最高人数（8 人）时，系统会自动封签。

玩家扫码处
固定二维码

二维码固定不变，玩家扫码后输入桌面展示的组局码。

① 左边一列：选哪一桌

  • 标题「进行中的组局」下面每一条就是一张桌子/一场局。左边 4 位数字是组局码，和桌面立牌上的一致。
  • 右上角「＋」= 新建组局。右侧小字 0/5 · 第 3 轮 表示「已经抽了 0 人 / 本轮 5 支签 · 第 3 轮」；写 5~8 人 · 尚未开轮 表示这局还没开轮。
  • 点哪一条，右边就切换到那一桌。
  • 最下面三个按钮：故事简介（玩家开场那段文字）、身份内容（每个身份的任务和奖励）、历史轮次（查以前的记录）。

② 右上角：玩家组局码

「玩家组局码」下面那个 4 位数字，就是要抄到桌面立牌上的数字。这个码建局时生成，之后不会变。

③ 中间一排按钮：现场最常按的

按钮什么时候按玩家那边会看到
开新轮（5~8人）每批玩家开始之前按一次。按之前玩家看到的是「吉时未至」。抽签界面出现，可以点「启 签」了
提前封签（需满5人）人数够了但不想再等。灰着点不动＝还没抽满最低人数。变成「本轮已封签」，只能等下一轮
组局设置 ▾ → 人数区间改这一桌的最低/最高人数。只影响之后新开的轮，正在进行的轮不变。没有变化（下一轮才生效）
组局设置 ▾ → 停用组局这一桌今天不用了。停用后「开新轮」按不动，列表里那一行变暗。玩家输入这个组局码会被直接拒绝，提示「该组局已经停用」

④ 四张数字卡：一眼看现场

  • 已落签：本轮已经被抽走的签数。余签：还剩几支。
  • 新郎 / 新娘：这两个身份有没有被抽走，什么时候抽走的。用来判断「关键身份都出去了没」。
  • 下面的进度条和「还需 N 人达到封签条件」会自动跳动，不用手动刷新。

⑤ 玩家扫码处：打印二维码

这里显示玩家要扫的二维码和地址，点「打印二维码」可以直接打印出来贴海报。二维码是固定的，做一次就行，以后不用换。

⑥ 最下面：已抽玩家

签序 / 身份 / 游客标识 / 抽取时间，用来核对「这张卡是不是这一轮抽的」。需要留档就点「导出 CSV」（Excel 能打开）。

4改文字：两个抽屉，改完立刻生效

所有文字都在管理端里改，改完保存，玩家刷新页面就能看到，不需要重启、不需要找人改代码。

「故事简介」——玩家开场读到的那一页

后台字段玩家端位置注意
标题（必填）大标题（现在显示为毛笔字「纸嫁衣」）如果标题改成别的名字，大标题会自动变回普通文字
副标题大标题下面那行金色小字—
故事简介（必填）红色的故事正文你按回车换行，玩家端就换行；空一行就是空一行
安全警告「入场须知」那个红框同样是换行等于换行

改完点右下角「保存故事简介」。玩家刷新页面后生效。

「身份内容」——每个身份的任务和奖励

  • 里面有新郎、新娘、村民三块，每块两个输入框：任务步骤（每行一步） 和 奖励文本。
  • 任务步骤：一行就是一条。写两行，玩家卡上就是「01 …」「02 …」两条编号任务。留空则显示「暂·无·任·务」。
  • 奖励文本：显示在身份卡的「线下赏礼」里。村民没有赏礼，所以村民卡上不会出现这一栏。
  • 改完点「保存全部内容」。重要：开轮时会把当时的内容复制一份到这一轮的签上，所以改内容不影响已经开出去的签，下一轮才用新内容。
什么时候改内容最安全？ 两轮之间。这样不会出现「同一轮里有人拿到旧任务、有人拿到新任务」。

5对照速查：后台点了什么 → 玩家看到什么

后台动作玩家端立刻的变化备注
新建组局无变化只是产生一个新的 4 位组局码，还没开轮
点「开新轮」「吉时未至」→ 变成「一签入命 / 启 签」玩家如果停在等待页，点「再探一次」或刷新即可
玩家点「启 签」身份卡出现后台「已落签」+1，并出现在「已抽玩家」表里
抽满最高人数后来的人看到「本轮签尽」系统自动封签
点「提前封签」后来的人看到「本轮已封签」需要有最低人数那么多人才按得动
改「故事简介」并保存玩家刷新后看到新文案已开着的页面需要刷新
改「身份内容」并保存无变化（本轮已复制的签不改）下一轮开出来的签才带新内容
改「人数区间」无变化下一轮生效
停用组局玩家再输这个组局码会被拒绝：「该组局已经停用」停用＝这一桌下线，最安全的"别再进人"开关。想恢复就点「重新启用」

6开场前 5 分钟，照着打勾

  • 服务器开着：管理端能正常登录（登录页点「登台理签」进得去）。
  • 组局建好了：左边列表里有这一桌，名字对、人数区间对。
  • 组局码抄对了：后台右上角「玩家组局码」的 4 位数字 = 桌面立牌上写的数字。这一条最容易出错。
  • 二维码：用自己手机扫一次海报上的二维码，能打开故事页。
  • 自己人先试一次：抽一张签，确认身份卡上的任务/奖励是你想要的文案。
  • 试完之后：让工作人员重新点一次「开新轮」，把试抽的签作废，正式玩家从干净的一轮开始。
  • 电脑别关、别锁屏、别切到睡眠；浏览器标签页保持打开。
  • 网络：确认现场 WiFi 能给玩家上网（玩家手机走的是现场网络）。

7出问题了？先看这张表

现象最可能的原因怎么办
玩家说「输不进组局码」 输到字母了；或者只输了 1~3 位 组局码只有 4 位数字。让玩家清空重输，看着立牌一位一位输。
玩家说「找不到这一局」 组局码输错，或后台提前封签/换轮了 核对立牌与后台右上角的数字是否一致。
玩家看到「吉时未至」 后台还没点「开新轮」 在后台点一次「开新轮（N~M人）」，让玩家点「再探一次」。
玩家看到「本轮签尽 / 已封签」 这一轮结束了 点「开新轮」，让玩家点「查看新轮」。
玩家说提示「该组局已经停用」 这一桌在后台被「停用组局」了 在后台选中那一桌 →「组局设置 ▾ → 重新启用」。
后台弹「连接不到现场服务器」 电脑与服务器之间断了一下（网络抖动，或服务器正在重启） 系统会自动重试 3 次。仍然失败就等几秒再点一次；重新点保存不会丢内容（窗口不会关）。
后台弹「请先登录管理端」 登录超时了 刷新页面，用管理员账号重新登录。
玩家抽完看不到新内容 / 还是旧的 手机缓存了旧页面 让玩家用无痕窗口打开，或清一下浏览器缓存再扫码。
二维码扫不出来 打印太小 / 反光 / 手机离太远 后台「玩家扫码处」点「打印二维码」重新打大一点；也可以让玩家手动输入网址。
后台的进度数字不动 页面与服务器的实时连接断了 它会自动重连；实在不动就刷新页面（不影响已抽的签）。
玩家说「抽到一半卡住了」 网络慢，正在抽 等 2 秒。若提示错误，让玩家再点一次「启 签」；同一台手机在同一轮只会有一张卡。

8两个「暂时别指望」的地方

这几处目前的真实情况，知道了就不会在现场白折腾。

  1. 停用的组局不会从列表里消失。「停用」这功能本身是管用的——玩家再输这个码会被直接拒绝（提示「该组局已经停用」），「开新轮」也按不动；但它只是把那一行变暗，仍然留在「进行中的组局」列表里。所以测试局想眼不见为净，目前只能忍着。
  2. 没有「删除组局」。测试局只能停用，删不掉。另外管理端只有一个管理员账号，多人同时操作没有权限区分，现场建议只让一个人碰后台。
这两条都能改：让列表默认把已停用的收起来（加一个「显示已停用」开关），或者加一个删除组局的功能（会连同该局的历史记录一起删）。说一声就行。
