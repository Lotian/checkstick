囍签 · 操作说明

二维码固定不变，印一次就一直用；组局码每桌一个，玩家要自己输入。

1管理端怎么操作

工作人员在电脑上操作。

  1. 打开管理端网址，用管理员账号和通行口令登录，点 登台理签。
  2. 新建一桌：点左上角 ＋ → 填现场名称（例如：10月8日 第1局）→ 设人数区间 → 点 生成组局码。
  3. 把右上角 玩家组局码 下面的 4 位数字 抄到桌面立牌上。这一步最容易出错，务必核对。
  4. 玩家进场前，点 开新轮（5~8人），一批签就放出来了。
  5. 看着中间四张数字卡：已落签 / 余签 / 新郎 / 新娘（会自动跳，不用刷新）。
  6. 人够了不想再等，点 提前封签；抽满最高人数，系统自己封。
  7. 下一批玩家，再点一次 开新轮 就行。
  8. 改文字：左边点 故事简介 或 身份内容 → 改完点保存。
    故事简介：玩家刷新页面后生效；身份内容：下一轮开出来的签才生效，不影响已经开出去的签。
  9. 打印二维码：右边 玩家扫码处 → 打印二维码。二维码固定不变，做一次就够了。
  10. 要查记录：右边「已抽玩家」表格，或点 导出 CSV。
人数规则：签位数量 = 你设的最高人数；抽满最低人数后 提前封签 才能点；抽满最高人数自动封签。
停用某一桌：选中它 → 组局设置 ▾ → 停用组局。停用后玩家输这个码会被拒绝，想恢复就点 重新启用。

2用户端怎么操作

玩家用自己的手机操作，工作人员只需在旁边告诉他立牌上的数字。

  1. 扫海报上的二维码。
  2. 读故事和入场须知，点 下 一 步。
  3. 输入桌面立牌上的 4 位数字，点 推 门 入 局。
    输入框永远是空的，不会自动填上次的码，必须自己输。
  4. 看到 一签入命 后，点 启 签，等 1~2 秒。
  5. 得到身份卡，按上面的任务行动，需要领奖时把卡给工作人员看。
  6. 看到 吉时未至：说明还没开轮，等工作人员开好后点 再 探 一 次。
  7. 看到 本轮签尽 或 本轮已封签：这一轮结束了，等下一轮开好，点 查 看 新 轮。
玩家要换一桌：点左上角 更换组局，重新输另一桌的组局码。
同一台手机在同一轮只会有一张卡，重复点 启 签 拿到的还是原来那张。
