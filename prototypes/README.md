# 囍签 · 玩家端界面原型（三版）

用《纸嫁衣》素材做的玩家端界面原型，用来给非技术同学挑"长相"。
功能与线上一致，差别只在**素材怎么用、整体气质**。

> **重要前提**：素材是《纸嫁衣》官方美术（含三个官方 logo）。
> 本文档里所有素材描述都是**逐张看过之后**写的，不是按文件名猜的。
> **logo 一律没有被使用**（它们是游戏自有品牌）。商用前请确认整包素材的授权范围。

## 怎么看

双击打开 **`index.html`**：一页里并排看到三版样式预览、说明、素材速览、后台改造示意。
每版下方按钮打开完整原型，原型左侧有一排状态按钮
（入局 / 候签 / 摇签 / 抽到新郎 / 抽到新娘 / 抽到村民 / 本轮签尽），点一下切换玩家的每一屏。

纯静态页面：不需要装东西、不需要联网、不需要跑服务。

```
prototypes/
  index.html          ← 先看这个
  v1-papercut.html    ← 版本一 · 红纸剪影（暗色 · 剪纸为主角）
  v2-cinema.html      ← 版本二 · 旧梦剧照（暗色 · 每屏一张剧照）
  v3-paper.html       ← 版本三 · 宣纸素签（浅色 · 不用照片背景）
  proto.css           ← 三版共用的手机框与组件（含自绘字标/印章样式）
  assets/             ← 已优化的素材（43MB → 4.96MB，可直接上线用）
  _raw/               ← 素材原始解包（可删；需要新素材时从 纸嫁衣素材.zip 重解）
```

## 三版对比

| | 版本一 · 红纸剪影 | 版本二 · 旧梦剧照 | 版本三 · 宣纸素签 |
|---|---|---|---|
| 底色 | 近黑深红 | 剧照铺满 + 暗玻璃卡 | 宣纸米白 |
| 主视觉 | 剪纸新娘/新郎（各带半个囍） | 每屏一张全屏剧照 | 剪纸 + 纸纹 |
| 身份卡 | 米色纸卡 | 暗色玻璃卡 | 白纸卡 + 朱砂描边 |
| 气质 | 克制、仪式感 | 电影感、有故事 | 明亮、亲和、好读 |
| 适合 | 厅内暗光 | 想传播、截图出片 | 白天户外、长辈多 |
| 照片用量 | 每屏 1 张（低透明度） | 每屏 1 张（满幅） | **0 张** |

## 图片处理说明

- 原图 43MB → 优化后 **4.96MB**（宣传图压到 1600px 宽 / JPEG 82，`shot-*` 压到 540×720）
- 剪纸双人图裁掉了左右空白（1400 → 744 宽），并按「囍」字中线切成两张半幅
- 角色立绘**没有抠图**：它们是不透明白底，卡片上用 `mix-blend-mode: multiply` 让白底融进纸色
- ⚠️ 例外：`char-*` 的 PNG 虽带 alpha 通道但并未使用，**不要**按透明切图处理

## 后台（管理端）改造要点

`index.html` 底部有一版示意。落地建议：

1. 侧栏顶部用自绘字标「囍签」，底部放 CSS 印章（**不要用游戏 logo**）；
2. 组局列表里 4 位组局码做成"红印章"式样；
3. 顶部标题条用一张剧照（`洞房.jpg` 或 `轿子3.jpg`）加 90% 暗色遮罩；
4. 「身份内容」抽屉里三个身份各配一张图：新郎/新娘用剪纸半幅，村民用 `老太婆.png`；
5. 登录页左半屏用 `新娘对镜.jpg` 或 `scene-sedan.jpg`。

## 选定之后怎么落地

1. 把 `prototypes/assets/` 里用到的图片放进 `player-web/src/assets/`（后台需要的同步一份）；
2. 按选定版本改写 `player-web/src/views/HomeView.vue` 与 `components/IdentityCard.vue` 的模板与样式
   —— **接口、状态机、字段都不动**（`PublicGroupState` / `DrawResult` / 4 位数字组局码逻辑保持不变）；
3. 后台按上面 5 点改 `admin-web`，二维码面板同步配色；
4. `npm run build` + 发布（照 `deploy/README.md`）。

## 已知限制

- 原型里的抽签数据是**写死的示例**（1024 组局码、新郎/新娘/村民三张卡），用于看样式，不接真实接口；
- 摇签动画是 CSS 动画（2.6s 循环），真实实现会与后端 1.9s 最短动画对齐；
- **授权**：素材为《纸嫁衣》官方美术，正式对外使用前请确认授权范围（尤其宣传物料）。
